# 📅 Shifree

一個純前端、支援離線使用的**排班表**應用程式。無需後端伺服器，所有資料儲存在瀏覽器的 LocalStorage 中。

## ✨ 功能特色

- **📅 排班日曆**：月曆檢視，支援左右滑動切換月份。
- **🧩 自訂模板**：建立專屬班別（名稱、簡稱、顏色、時間），支援拖拽排序。
- **⚡ 快捷排班**：快速新增 / 快速刪除模式，支援拖拽選取連續日期。
- **📝 每日備註**：在日曆上直接記錄當天注意事項。
- **🎨 自訂色板**：支援系統取色器，可自由新增或刪除顏色。
- **📦 多格式備份**：支援 JSON 備份還原、CSV 匯出（Google 日曆）、ICS 匯出與還原。
- **📱 響應式設計**：適用手機、平板與電腦。
